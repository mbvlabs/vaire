## Phase 1: Bootstrap

- [ ] **A broken tunnel during lockdown reverts by itself**
    - On a fresh VPS, start `eru server init --host root@<vps>` and break WireGuard during the commit-confirm move of SSH to wg0 (for example, block the WireGuard UDP port on the laptop).
    - Expected: the node restores public SSH on 22 by itself after the confirm window, and `eru server init --resume` can carry on.
- [ ] **`server init --local`**
    - On a fresh VPS, install with `curl | sudo bash`, run `eru server init --local`, paste the transfer bundle into `eru login` on the laptop, and run `eru plan` from there.

- [ ] **Direct TLS on 443**

Found while testing (2026-10-12, on the shared-cluster build before the Phase 3 rework):

- Fixed: `postgres-config-v1` restarted PostgreSQL on every change without the confirm token and recorded `restart: none`.
- Fixed: `backup list` showed `IN REPO 0 B`, because pgBackRest 2.59 omits `repository.size`.
- Fixed: `backup setup` showed the cluster-password warning for a new recovery kit.
- Fixed: `< /dev/null` did not count as a non-terminal stdin.
